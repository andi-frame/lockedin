# ADR-0009: Visual direction: Buku Tabungan (passbook)

Status: Accepted (2026-10-07). Chosen by the product owner in the impeccable direction round (seed 430d207e).

## Decision
The app shell is an Operate surface modelled on an Indonesian bank passbook:
- The pot is shown as passbook lines: date / description / debit / credit / saldo.
- The signature move is "passbook print": each new ledger line types itself in.
- Stamp violet is used only for human decisions.
- Highlighter yellow is used only for today.

The full direction contract is in `.impeccable/surfaces/apps-web-src-app-app.md`. The impeccable documenter writes `DESIGN.md` after the first UI build.

## Rejected
- **LJK answer sheet:** too familiar, and it carries exam-stress connotations.
- **Category standard (habit tracker / fintech):** rejected.
- **Catalog challengers:** split-flap board, transit map, design annual plate, doujin catalog, reference setting, orienteering map. Each one contributed a discipline as a raise to the chosen direction; see the contract.
