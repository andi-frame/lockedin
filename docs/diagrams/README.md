# Diagrams

These are interactive HTML diagrams generated by the *archify* skill. Open them in a browser. Each one has dark/light themes and can export PNG or SVG.

| Diagram | Type | Source of truth |
|---|---|---|
| [architecture/tepati-architecture.html](architecture/tepati-architecture.html) | architecture | `docs/ARCHITECTURE.md §1` |
| [checkin-lifecycle/checkin-lifecycle.html](checkin-lifecycle/checkin-lifecycle.html) | lifecycle | `docs/SPEC.md §5` |
| [upload-sequence/upload-sequence.html](upload-sequence/upload-sequence.html) | sequence | `docs/ARCHITECTURE.md §6` |

The diagrams are derived from the docs, so they never override them. When the source section changes:

1. Edit `candidate.json` in the diagram's folder.
2. Re-run `node ~/.claude/skills/archify/bin/archify.mjs finalize <type> <candidate.json> <output.html> --quality showcase --json`.
3. Delete stale `*.browser-check.json` evidence if finalize refuses to overwrite it.
